- [ ] **Step 4: 写入可复制的番茄榜单、详情和整本 TXT 操作链**

PowerShell 示例必须复用响应数据，不能写死真实书号：

```powershell
$baseUrl = "http://localhost:3000"
$rankTypeKey = "0_1_1139"

$ranking = Invoke-RestMethod `
  -Method Post `
  -Uri "$baseUrl/v1/rankings/fanqie/$rankTypeKey/refresh"

$bookId = $ranking.items[0].externalBookId
$book = Invoke-RestMethod `
  -Method Get `
  -Uri "$baseUrl/v1/books/fanqie/$bookId"

$download = Invoke-RestMethod `
  -Method Post `
  -Uri "$baseUrl/v1/books/fanqie/$bookId/downloads" `
  -ContentType "application/json; charset=utf-8" `
  -Body "{}"

$downloadId = $download.id
$activeStatuses = @("queued", "running", "canceling")
do {
  $task = Invoke-RestMethod `
    -Method Get `
    -Uri "$baseUrl/v1/downloads/$downloadId"

  if ($task.status -in $activeStatuses) {
    Start-Sleep -Seconds 1
  }
} while ($task.status -in $activeStatuses)

$task | Select-Object status, progress, error

if ($task.status -eq "succeeded") {
  Invoke-WebRequest `
    -Uri "$baseUrl/v1/downloads/$downloadId/file" `
    -OutFile ".\novel-$bookId.txt"
}
```

在代码块后说明刷新成功应有 10 项、`$book.stale` 的含义、任务只有 `succeeded` 才能下载文件。

- [ ] **Step 5: 补充范围下载、取消、删除、全量榜单和日常启停**

范围下载使用 1-based 闭区间且两个字段同时出现：

```powershell
$rangeBody = @{ startChapter = 20; endChapter = 30 } | ConvertTo-Json
$rangeDownload = Invoke-RestMethod `
  -Method Post `
  -Uri "$baseUrl/v1/books/fanqie/$bookId/downloads" `
  -ContentType "application/json; charset=utf-8" `
  -Body $rangeBody
```

任务操作示例：

```powershell
Invoke-RestMethod -Method Post -Uri "$baseUrl/v1/downloads/$downloadId/cancel"
Invoke-RestMethod -Method Delete -Uri "$baseUrl/v1/downloads/$downloadId"
```

说明六种状态；取消只适用于非终态任务，`running` 先进入 `canceling`；只有 `succeeded`、`failed`、`canceled` 可删除。列出起点键 `yuepiao`、`hotsales`、`recom`、`collect`，并提醒 `POST /v1/rankings/fanqie/refresh` 会串行访问 74 个榜单，不作为首次验证命令。日常顺序为先 Downloader 后 API，停止顺序相反，两个进程都以前台方式运行。
